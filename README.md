                         Finora – Personal Finance Dashboard

Finora is a personal finance dashboard designed to help users manage their financial activities through transaction tracking, budget management, and savings goals.

Features

User Authentication – User registration and login.

Transaction Management – Track income and expenses.

Budget Management – Create and manage budgets by category.

Savings Goals – Set savings targets and track saved amounts.

Database Integration – Store and manage financial data using MySQL.

Frontend and Backend Integration – Connect the user interface with backend APIs.

Technologies Used

Frontend
-React.js
-Vite
-JavaScript
-CSS

Backend
-PHP
-Laravel
-REST API

Database
-MySQL
